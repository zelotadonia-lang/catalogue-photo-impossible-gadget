A catalogue photograph of an impossible gadget: a solar-powered flashlight that only works because it keeps a miniature sun in a glass jar beside it, wired in. The program draws the studio shot pixel by pixel — backdrop, floor shadow, beam, metal body, jarred sun — with no dependencies and no network, and writes it to `/output/entry.png` as a 1024x1024 PNG.

## Run it

```sh
node main.ts
```
